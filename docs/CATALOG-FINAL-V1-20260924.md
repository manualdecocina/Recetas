## Regla de lanzamiento
Una URL entra en LAUNCH solo si tiene entidad aprobada, tipo de contenido aprobado, URL definitiva, contenido nuevo completo, imagen válida, schema cuando corresponde, canonical, hreflang cuando corresponde, enlace interno, sitemap y QA.

El resto permanece STAGING, REVIEW o OUT.
