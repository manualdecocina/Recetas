# FASE 1M.1 — DIRECCIÓN DE MARCA Y LOGO
## Manual de Cocina — 2026-09-25

Estado: **DIRECCIÓN CERRADA PARA DISEÑO / ARTE FINAL PENDIENTE**

## Objetivo
Construir una marca que pueda vivir fuera de la web y que siga identificándose en favicon, cabecera, receta impresa, redes y posibles soportes futuros.

## Referencia conceptual
La referencia existente aportada para la marca establece:
- una ficha/documento de cocina con esquina doblada;
- un recipiente/cazuela reconocible en el interior;
- vapor;
- wordmark “manual” con peso fuerte;
- “de cocina” en tamaño menor y peso más ligero;
- composición vertical;
- tratamiento esencialmente monocromático.

La referencia se usa como punto de partida conceptual, no para copiarla literalmente.

## Dirección elegida
**Wordmark primero + símbolo secundario independiente.**

La marca debe poder reconocerse por el nombre “Manual de Cocina” incluso sin símbolo.

### Wordmark
- “manual” es el elemento dominante.
- “de cocina” funciona como descriptor.
- composición limpia y editorial.
- evitar lettering excesivamente artesanal.
- evitar estética de restaurante gourmet.
- evitar estética de supermercado.
- evitar iconos genéricos de cubiertos.

### Símbolo
Debe comunicar la idea de **manual/ficha + cocina**, no “cocina” de manera genérica.
Puede partir de la idea documento/ficha + recipiente + vapor, pero debe reducirse a una geometría muy simple.
El símbolo no debe parecer un objeto sanitario, doméstico ambiguo ni una silueta accidental.

### Color
El logo maestro debe existir en:
1. monocromo carbón sobre fondo claro;
2. blanco sobre fondo oscuro;
3. versión compatible con el sistema de color;
4. símbolo aislado.

No depender de fotografía ni textura.

### Versiones obligatorias
- horizontal;
- vertical;
- compacta;
- símbolo;
- favicon;
- monocroma clara;
- monocroma invertida.

### Favicon
No será una miniatura del logo completo.
Debe ser un símbolo independiente, legible a tamaños muy pequeños y reconocible en una pestaña.

### Restricciones
No usar:
- cuchillo/tenedor genérico;
- chef/toque de chef;
- gorro de cocinero;
- llama genérica;
- plato genérico;
- tomate/chile genérico;
- ilustración compleja;
- sombras o degradados necesarios para reconocer la marca.

## Prueba de calidad
El concepto solo pasa si funciona:
- a 16–32 px como favicon;
- a ~120 px en cabecera móvil;
- a ~180–240 px en cabecera desktop;
- en impresión monocroma;
- en fondo claro y oscuro;
- sin perder la palabra “manual”.
