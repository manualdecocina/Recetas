## Criterio

En esta tanda se priorizan:
- posición histórica < 15;
- o señales de clics/impresiones suficientes para justificar reconstrucción;
- entidad culinaria clara;
- presencia en inventario y/o Supabase.

No se considera el redirect existente como prueba de que el destino actual sea definitivo.
