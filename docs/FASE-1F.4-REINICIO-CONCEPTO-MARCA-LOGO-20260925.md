# FASE 1F.4 — REINICIO DEL CONCEPTO DE MARCA / LOGO

**Proyecto:** Manual de Cocina  
**Dirección visual aprobada:** Editorial culinaria  
**Estado:** EXPLORACIÓN REINICIADA — LOGO ANTERIOR DESCARTADO  
**Fecha:** 2026-09-25

---

## 1. FEEDBACK DE DISEÑO

Las tres rutas anteriores:

- A — Monograma editorial
- B — Página / marcador
- C — Editorial + cocina abstracta

quedan **DESCARTADAS** como líneas de desarrollo.

No se seleccionará ninguna de ellas ni se intentará rescatar una por inercia.

La conclusión de esta ronda es importante:

> El problema no es elegir mejor entre esos tres símbolos. El problema es que empezamos por el símbolo.

---

## 2. NUEVA REGLA DE TRABAJO

A partir de esta fase, el logo se desarrollará **wordmark-first**.

Primero debe funcionar:

**MANUAL DE COCINA**

como marca tipográfica.

Después se estudiará si realmente necesita un símbolo independiente.

No se presupone que toda marca necesite un icono.

---

## 3. QUÉ QUEREMOS CONSEGUIR

Manual de Cocina debe sentirse:

- editorial;
- culinario;
- contemporáneo;
- reconocible;
- serio sin ser institucional;
- cálido sin ser rústico;
- sofisticado sin ser elitista;
- útil y digital;
- capaz de vivir durante años sin depender de una tendencia gráfica.

La identidad debe parecer una **marca editorial culinaria propia**, no una plantilla de blog gastronómico ni una marca genérica de restaurante.

La investigación reciente de identidad y publicaciones culinarias muestra que la tipografía, la jerarquía editorial, la fotografía y el sistema completo pueden cargar gran parte de la identidad; no es obligatorio que el reconocimiento dependa de un símbolo gastronómico. citeturn0search0turn0search9

# 4. NUEVO TERRITORIO A — WORDMARK PURO

El nombre completo es el logo.

No hay icono.

### Exploración

**Manual de Cocina**

Variaciones:

- serif de alto contraste;
- serif editorial de contraste medio;
- serif contemporánea;
- sans editorial;
- mezcla de pesos;
- composición en dos líneas;
- composición horizontal.

### Objetivo

Que el propio nombre tenga suficiente personalidad para reconocerse sin símbolo.

### Ventaja

Máxima claridad y mínima dependencia de un recurso gráfico externo.

### Riesgo

La tipografía debe ser suficientemente distintiva.

---

# 5. NUEVO TERRITORIO B — WORDMARK + GESTO EDITORIAL

El nombre sigue siendo protagonista.

Se añade un gesto gráfico mínimo:

- una línea;
- una regla;
- un subrayado;
- una separación;
- una numeración;
- una pequeña marca de edición;
- una composición de título de capítulo.

No debe convertirse en un icono.

La identidad nace de la **manera de componer el nombre**.

Conceptualmente:

> portada de libro + herramienta digital.

---

# 6. NUEVO TERRITORIO C — MARCA TIPOGRÁFICA DE DOS NIVELES

Explorar la jerarquía del propio nombre:

**MANUAL**  
de Cocina

o

**Manual**  
**DE COCINA**

o

**Manual de**  
**Cocina**

El objetivo es encontrar una composición que haga que el nombre parezca una cabecera editorial propia.

No se utilizará un monograma como sustituto.

---

# 7. NUEVO TERRITORIO D — IDENTIDAD DE FICHA / RECETARIO

No se trata de dibujar una página.

La referencia está en el **lenguaje gráfico de un manual real**:

- numeración;
- capítulos;
- fichas;
- referencias;
- pequeñas reglas;
- índices;
- etiquetas editoriales;
- composición tipográfica.

El logo puede ser principalmente tipográfico, mientras que este lenguaje se convierte en el sistema reconocible de la marca.

Esto permitiría que el sitio tenga personalidad incluso cuando el logo aparezca en tamaño pequeño.

---

# 8. SÍMBOLO: AHORA ES OPCIONAL

Solo se creará un símbolo independiente si aparece de forma natural después de resolver el wordmark.

No se diseñará un icono simplemente porque:

> “una marca necesita un icono”.

Si no aparece una forma propia y memorable, el sistema podrá funcionar con:

**wordmark + lenguaje editorial + favicon tipográfico/geométrico derivado.**

---

# 9. NUEVO CRITERIO PARA EL FAVICON

No se diseñará todavía.

Primero debe existir una identidad que merezca ser reducida.

Se probarán posteriormente:

1. inicial;
2. fragmento tipográfico;
3. gesto editorial;
4. símbolo, solo si aparece;
5. solución puramente geométrica derivada del sistema.

---

# 10. COSAS QUE QUEDAN FUERA

---

# 11. PRUEBA DE CALIDAD

Cada nueva propuesta deberá responder afirmativamente a estas preguntas:

### 1. ¿Funciona escrita solo con el nombre?

### 2. ¿Parece una marca y no simplemente una tipografía elegida?

### 3. ¿Tiene personalidad propia?

### 4. ¿Se reconoce en una cabecera pequeña?

### 5. ¿Funciona en blanco y negro?

### 6. ¿Puede aparecer en una portada de libro?

### 7. ¿Puede aparecer en una interfaz digital?

### 8. ¿Sigue funcionando sin fotografía?

### 9. ¿Encaja con recetas de cualquier cocina del mundo?

### 10. ¿Dentro de cinco años seguirá pareciendo válida?

# 12. SIGUIENTE RONDA

La siguiente exploración visual **NO** mostrará tres iconos diferentes.

Mostrará varias soluciones de:

**MANUAL DE COCINA**

como marca real.

Cada propuesta deberá enseñarse aplicada en:

- logo principal;
- cabecera desktop;
- cabecera móvil;
- tarjeta de receta;
- portada editorial;
- favicon provisional;
- monocromo.

Solo después de encontrar una dirección tipográfica convincente se decidirá si hace falta símbolo.
