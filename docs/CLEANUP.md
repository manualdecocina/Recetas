# LIMPIEZA — CONTRATO EDITORIAL

**Fecha:** 2026-09-24  
**Estado:** ACTIVO — Sprint 0

## Objetivo

El nuevo Manual de Cocina no es una copia del WordPress histórico. El histórico se utiliza como evidencia para decidir qué merece reconstrucción.

## Filtro obligatorio

Cada URL/contenido histórico debe pasar cuatro filtros:

1. **Relevancia:** ¿pertenece realmente a Manual de Cocina?
2. **Originalidad:** ¿es una entidad propia o un clon/duplicado?
3. **Valor editorial:** ¿podemos crear una página útil y completa?
4. **Modelo de negocio actual:** ¿forma parte del proyecto actual o existía principalmente para afiliación/monetización abandonada?

## Eliminar del nuevo catálogo

Quedan fuera, salvo una decisión posterior excepcional y documentada:

- páginas de batidoras;
- comparativas de productos creadas para Amazon;
- contenido de afiliación cuyo propósito principal ya no existe;
- clones y páginas casi idénticas;
- contenido ajeno a cocina/alimentación/editorial del proyecto;
- páginas creadas únicamente para capturar búsquedas sin una entidad útil detrás;
- contenido histórico que no pueda justificarse como parte del nuevo catálogo.

## Conservar/reconstruir

Se priorizan:

- recetas reales;
- colecciones de recetas útiles;
- artículos editoriales de cocina/alimentación;
- páginas institucionales necesarias;
- entidades multilingües históricas que tengan una equivalencia editorial clara;
- contenido que tenga valor histórico SEO y pueda reconstruirse con valor real para el usuario.

## Duplicados

Cuando varias URLs representan la misma entidad e intención, se crea una sola entidad editorial.

La resolución será:

- conservar la URL histórica de mayor valor cuando sea razonable;
- redirigir las variantes coherentes hacia la URL canónica elegida;
- no crear múltiples páginas nuevas para el mismo contenido;
- no conservar clones solo porque tengan URLs diferentes.

## Contenido de afiliación

La ausencia de Amazon como modelo de monetización significa que no se reconstruye una sección de productos para sustituir ingresos antiguos.

Una página de producto solo podría entrar en el nuevo catálogo si tiene una función editorial independiente que encaje con la misión de Manual de Cocina y sea aprobada explícitamente.

## Tratamiento SEO de lo eliminado

Eliminar del catálogo editorial no implica borrar una URL sin análisis.

Para cada URL retirada se documentará:

- tráfico histórico;
- impresiones;
- intención;
- relación con otras URLs;
- existencia de una equivalencia real;
- acción final: `MERGE`, `301` o `404/410`.

No se redirige una página irrelevante a una receta únicamente para conservar señales históricas. Google considera legítimos los redirects para migraciones y consolidaciones coherentes; los redirects que llevan a contenido significativamente diferente pueden ser considerados problemáticos. citeturn0search2

## Regla de calidad

No se crea contenido masivo únicamente para aumentar el número de URLs. Google define el abuso de contenido a escala en términos de páginas generadas principalmente para manipular rankings y con poco valor para usuarios; esta regla se aplica independientemente de si el contenido se genera manualmente, automáticamente o mediante IA. citeturn0search2

## Resultado esperado

El nuevo catálogo debe ser **más limpio que el histórico**, no igual de grande.

El objetivo es que cada URL nueva pueda responder claramente a estas preguntas:

- ¿qué entidad representa?
- ¿para quién existe?
- ¿qué intención satisface?
- ¿qué valor aporta?
- ¿por qué debe existir como URL independiente?

Si no podemos responderlas, la URL no entra automáticamente al nuevo catálogo.
