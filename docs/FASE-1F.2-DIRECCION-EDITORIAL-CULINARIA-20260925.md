# FASE 1F.2 — DIRECCIÓN DE MARCA SELECCIONADA: EDITORIAL CULINARIA

**Proyecto:** Manual de Cocina  
**Dominio:** manualdecocina.com  
**Estado:** DIRECCIÓN SELECCIONADA PARA DESARROLLO — PENDIENTE DE CIERRE VISUAL  
**Fecha:** 2026-09-25

---

## 1. DECISIÓN

Se selecciona **A — Editorial culinaria** como territorio principal para desarrollar la identidad de Manual de Cocina.

Esto no significa que el producto vaya a convertirse en una revista.

La decisión es:

> **La marca tendrá alma editorial; la arquitectura seguirá siendo una herramienta culinaria.**

La UX, búsqueda, filtros y modo cocina definidos anteriormente no se modifican.

---

# 2. POR QUÉ ESTA DIRECCIÓN ENCAJA

La dirección editorial permite que Manual de Cocina comunique:

- conocimiento;
- confianza;
- cultura culinaria;
- calidad;
- fotografía;
- permanencia;
- descubrimiento.

Además permite crecer más allá de las recetas hacia:

- guías;
- técnicas;
- ingredientes;
- cocinas;
- colecciones;
- contenido editorial.

Referencias actuales de diseño culinario muestran que una combinación de serif para titulares y sans para lectura/interfaz puede aportar carácter editorial sin sacrificar legibilidad. Crumb, por ejemplo, utiliza Cormorant Garamond + Inter en varias de sus direcciones de receta y mantiene la fotografía como elemento protagonista. citeturn0search11turn0search4

Fine Cooking también documenta un enfoque de marca integrada donde identidad, tipografía, iconografía, fotografía y experiencia digital forman un sistema coherente. citeturn0search5

---

# 3. POSICIONAMIENTO VISUAL

La frase de trabajo es:

> **Un buen libro de cocina convertido en una herramienta digital.**

No:

> una revista digital con recetas.

La diferencia es importante.

### Editorial

Aporta:

- jerarquía;
- ritmo;
- fotografía;
- tipografía;
- criterio.

### Producto

Aporta:

- búsqueda;
- filtros;
- navegación;
- interacción;
- lectura práctica;
- modo cocina.

Ambos deben coexistir.

---

# 4. PRINCIPIO VISUAL

## Menos decoración. Más criterio.

La interfaz no debe intentar demostrar que sabe diseñar.

Debe crear un entorno donde:

**la comida + el contenido + la estructura**

sean los protagonistas.

Este principio está respaldado por referencias actuales de sitios de recetas que reducen elementos decorativos para dejar respirar a la fotografía y utilizan una base limpia con serif display + sans funcional. citeturn0search11turn0search1

# 6. POR QUÉ NO UNA PALETA MULTICOLOR

Manual de Cocina tendrá cientos/miles de fotografías.

Si además la interfaz utiliza muchos colores:

- se pierde jerarquía;
- las tarjetas compiten con las imágenes;
- el sistema se vuelve difícil de mantener;
- la marca pierde reconocimiento.

Por tanto:

> **base neutra + un acento reconocible + fotografía como fuente principal de color.**

Esta estrategia también aparece en sistemas de recetas actuales como Vanilla y Mandarin, donde se restringe deliberadamente el color de interfaz para no competir con la comida. citeturn0search11turn0search16

# 7. TIPOGRAFÍA — PRIMERA DIRECCIÓN

## Display

Familia serif editorial.

Características buscadas:

- contraste moderado;
- elegante;
- cálida;
- excelente en títulos grandes;
- personalidad sin parecer antigua.

Candidatas para pruebas posteriores:

- Cormorant Garamond;
- Source Serif 4;
- Fraunces;
- Lora.

No se selecciona todavía una fuente definitiva.

## UI / Body

Sans muy legible.

Características:

- excelente lectura móvil;
- números claros;
- buena legibilidad en ingredientes;
- pesos suficientes;
- buen comportamiento en botones y filtros.

Candidatas:

- Inter;
- Source Sans 3;
- Manrope;
- IBM Plex Sans.

No se selecciona todavía una fuente definitiva.

---

# 8. REGLA TIPOGRÁFICA

La serif expresa:

> **qué es Manual de Cocina.**

La sans expresa:

> **cómo funciona Manual de Cocina.**

Por tanto:

### Serif

- H1;
- títulos de recetas;
- grandes titulares;
- nombres de colecciones;
- grandes frases editoriales.

### Sans

- ingredientes;
- instrucciones;
- navegación;
- filtros;
- botones;
- metadatos;
- búsqueda;
- estados.

No usar serif para instrucciones largas.

---

# 9. FOTOGRAFÍA

La fotografía será uno de los pilares de la identidad.

## Dirección

**Real, apetecible, editorial y humana.**

Preferencias:

- luz natural o naturalista;
- textura visible;
- ingredientes reconocibles;
- platos reales;
- composición limpia;
- profundidad;
- variedad cultural;
- evitar exceso de utilería.

El enfoque debe permitir que una receta colombiana, japonesa, italiana o mexicana siga perteneciendo visualmente a la misma marca.

---

# 10. FOTOGRAFÍA DE RECETA

La fotografía principal debe poder utilizarse en:

- hero;
- card;
- página de receta;
- resultados de búsqueda;
- colección;
- redes/compartidos;
- Open Graph.

Por eso la biblioteca de medios debe soportar distintos recortes.

No diseñaremos la UI alrededor de una única relación de aspecto.

---

# 11. COMPOSICIÓN

La composición editorial utilizará:

- grandes márgenes;
- retícula;
- alineación clara;
- bloques de contenido;
- espacios de respiración;
- reglas finas;
- jerarquía tipográfica.

La intención es que el sitio pueda sentirse cuidadosamente editado incluso cuando el usuario esté simplemente buscando “pollo”.

---

# 12. RECURSO EDITORIAL PROPIO

Para evitar que parezca simplemente “otra web con serif”, necesitamos un recurso reconocible.

Primera hipótesis:

## Las reglas editoriales

Pequeñas líneas, numeración y separadores utilizados de manera consistente.

Ejemplo:

```
01 — INGREDIENTES
────────────────────

02 — PREPARACIÓN
────────────────────

03 — CONSEJOS
────────────────────
```

Debe ser sutil.

No queremos una estética de periódico.

---

# 13. TARJETA DE RECETA

Dirección:

```
┌──────────────────────────────┐
│                              │
│          FOTOGRAFÍA          │
│                              │
├──────────────────────────────┤
│ Pollo al ajillo              │
│                              │
│ 35 min · Fácil               │
│ Platos principales           │
└──────────────────────────────┘
```

Reglas:

- imagen grande;
- título serif;
- metadatos sans;
- máximo contexto necesario;
- sin exceso de badges;
- sin sombras exageradas;
- sin decoración innecesaria.

---

# 14. HOME

La Home debe sentirse editorial desde el primer segundo.

Pero su primera acción sigue siendo:

> **¿Qué quieres cocinar?**

Por tanto:

### Editorial

- fotografía;
- titulares;
- colecciones;
- historias.

### Producto

- búsqueda;
- navegación;
- categorías.

No sacrificar la herramienta por estética.

---

# 15. PÁGINA DE RECETA

La página tendrá una estructura editorial más refinada, pero conservará el modelo funcional ya definido:

```

                  01
                  ...

                  02
                  ...

────────────────────────

VÍDEO
```

La estética será editorial.

La interacción seguirá siendo de producto.

---

# 16. MODO COCINA

El modo cocina será deliberadamente menos editorial.

Esto es importante.

Cuando una persona cocina:

**la herramienta gana.**

Por tanto, el modo cocina utilizará:

- tipografía más funcional;
- controles grandes;
- menos decoración;
- alto contraste;
- progreso;
- navegación simple.

La marca seguirá presente mediante:

- símbolo;
- tipografía;
- color;
- pequeños detalles.

Pero nunca debe interferir con la lectura.

---

# 17. LOGO — NUEVA DIRECCIÓN

Ahora que A está seleccionada, el logo debe explorar **editorial + cocina + manual**, no “utensilio culinario genérico”.

### Territorios de símbolo

**1. Monograma**
Una M construida con lógica editorial.

**2. Página**
Una referencia abstracta a una hoja/libro/ficha.

**3. Marcador**
Una forma de índice o marcador de libro.

**4. Capítulo**
Una forma basada en numeración/sección.

**5. Gesto culinario abstracto**
Solo si puede integrarse con el concepto editorial.

Todavía no se elige ninguno.

---

### A

- símbolo encima;

# 19. FAVICON

El favicon deberá nacer del símbolo.

No del wordmark.

Candidatos conceptuales:

- M;
- marcador;
- esquina de página;
- símbolo editorial;
- monograma MC simplificado.

Debe sobrevivir a:

**16 × 16 px.**

---

# 20. ICONOGRAFÍA

La iconografía será:

- lineal;
- fina;
- sencilla;
- geométrica;
- consistente.

No utilizar ilustraciones complejas como iconos de interfaz.

---

# 21. FORMAS

Preferencia inicial:

- esquinas ligeramente redondeadas o cuadradas;
- evitar pills excesivas;
- bordes finos;
- sombras mínimas;
- superficies limpias.

El objetivo es aproximarse más a:

**libro + revista contemporánea**

que a:

**app de tarjetas redondeadas**.

---

# 22. TONO VISUAL

Manual de Cocina debe parecer:

**culto sin ser pretencioso.**

**bonito sin ser decorativo.**

**experto sin ser elitista.**

**digital sin parecer tecnológico.**

**culinario sin recurrir a clichés.**
