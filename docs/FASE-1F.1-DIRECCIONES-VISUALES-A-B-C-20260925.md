# 3. DIRECCIÓN A — EDITORIAL CULINARIA

## Concepto

**Manual de Cocina como publicación gastronómica contemporánea.**

Debe sentirse como una revista/libro culinario digital con una herramienta potente debajo.

### Palabras clave

- editorial
- criterio
- cultura
- fotografía
- sofisticación
- composición

## Tipografía candidata

**Display:** serif de alto contraste.

**UI/body:** sans neutra.

La serif se reservaría para:

- títulos;
- nombres de colecciones;
- grandes mensajes editoriales.

La sans dominaría:

- ingredientes;
- instrucciones;
- navegación;
- filtros;
- botones.

## Color

Base:

- blanco roto;
- carbón;
- gris cálido.

Acento muy limitado.

La fotografía aporta la mayor parte del color.

## Fotografía

- grande;
- protagonista;
- encuadres editoriales;
- textura;
- luz natural/controlada;
- poca intervención gráfica.

## Recursos gráficos

- líneas finas;
- numeración discreta;
- grandes espacios;
- pequeñas etiquetas editoriales.

## Logo

Wordmark elegante, con símbolo secundario muy simple.

El símbolo podría explorar:

- una M;
- una referencia a página/capítulo;
- un monograma;
- una marca editorial.

No se aprueba todavía ningún símbolo concreto.

## Favicon

Monograma o símbolo geométrico muy reducido.

## Cómo se vería una receta

Sensación:

> “Estoy consultando un buen libro de cocina digital.”

## Fortalezas

- autoridad;
- longevidad;
- buena relación con fotografía;
- extensible a guías y artículos;
- aspecto premium sin necesitar ornamento.

## Riesgos

- puede parecer una revista;
- puede disminuir la sensación de herramienta;
- requiere mucho cuidado para que los controles no parezcan secundarios.

# 4. DIRECCIÓN B — MANUAL CONTEMPORÁNEO

## Concepto

**La palabra “Manual” se convierte en el sistema visual.**

No pretende parecer un manual técnico antiguo.

Es una interpretación digital contemporánea de:

- instrucciones;
- fichas;
- capítulos;
- índices;
- pasos;
- anotaciones;
- referencias.

### Palabras clave

- precisión;
- utilidad;
- sistema;
- estructura;
- conocimiento;
- confianza.

## Tipografía candidata

**Display:** serif o grotesca con personalidad moderada.

**UI/body:** sans muy legible.

Posible utilización de una fuente monoespaciada o de ancho controlado solo para pequeños elementos técnicos:

- números de paso;
- tiempos;
- índices;
- códigos.

No para lectura larga.

## Color

Base neutra:

- papel claro / blanco roto;
- carbón;
- gris.

Acento único fuerte.

El color funciona como señal:

- acción;
- selección;
- categoría;
- estado.

## Fotografía

Más documental que publicitaria.

La comida sigue siendo atractiva, pero la imagen no necesita dominar toda la página.

## Recursos gráficos

Aquí aparece el elemento diferencial:

- numeración;
- reglas;
- divisores;
- pequeños marcadores;
- etiquetas;
- capítulos;
- índices;
- llamadas;
- símbolos propios.

Ejemplo:

```
01 PREPARAR
02 COCINAR
03 TERMINAR
```

## Logo

Esta dirección tiene más espacio conceptual para un símbolo propio.

Posibles territorios:

- M modular;
- página;
- marca de índice;
- esquina/página;
- paso;
- símbolo de referencia.

Evitar utensilios literales.

## Favicon

Idealmente un símbolo construido específicamente para funcionar en pequeño.

## Cómo se vería una receta

Sensación:

> “Este sitio sabe cómo enseñarme a cocinar.”

## Fortalezas

- encaja directamente con el nombre;
- muy compatible con modo cocina;
- muy escalable;
- diferencia mejor el producto de un blog;
- puede crear un lenguaje gráfico propio;
- funciona en categorías, guías y colecciones.

## Riesgos

- puede volverse demasiado técnico;
- necesita fotografía cálida para compensar;
- demasiadas líneas/etiquetas destruirían la simplicidad.

# 5. DIRECCIÓN C — COCINA VIVA

## Concepto

**Manual de Cocina como lugar al que apetece volver.**

Más humano y emocional.

### Palabras clave

- hogar;
- sabor;
- descubrimiento;
- espontaneidad;
- cercanía;
- apetito.

## Tipografía candidata

**Display:** serif cálida o sans con personalidad.

**UI/body:** sans muy legible.

Posibles detalles manuscritos solo para pequeñas anotaciones, nunca para instrucciones críticas.

## Color

Paleta más cálida:

- crema;
- carbón;
- terracota / arcilla / verde culinario como candidato.

El color debe ser moderado para no competir con la comida.

## Fotografía

La protagonista.

- comida real;
- manos;
- preparación;
- ingredientes;
- mesas;
- pequeñas imperfecciones;
- escenas de cocina.

No todo debe parecer una sesión publicitaria.

## Recursos gráficos

- pequeños trazos;
- etiquetas;
- gestos manuales;
- formas orgánicas;
- ilustraciones puntuales.

## Logo

Más humano.

Puede explorar:

- monograma;
- símbolo orgánico;
- gesto gráfico;
- combinación de M + elemento culinario abstracto.

No se acepta un icono culinario genérico.

## Favicon

Símbolo sencillo, con silueta clara.

## Cómo se vería una receta

Sensación:

> “Quiero cocinar esto.”

## Fortalezas

- mucha calidez;
- gran potencial fotográfico;
- atractivo para colecciones;
- buena conexión emocional;
- fácil de hacer apetecible.

## Riesgos

- puede parecer blog;
- menor diferenciación;
- puede perder la idea de “manual”;
- puede caer en códigos visuales culinarios muy utilizados.

# 7. MATRIZ DE EVALUACIÓN

La decisión no será “me gusta más”.

Se evaluará cada dirección de 1 a 5 internamente según:

- reconocimiento;
- relación con “Manual”;
- claridad;
- utilidad;
- calidez;
- diferenciación;
- escalabilidad;
- legibilidad móvil;
- capacidad de funcionar con fotografía diversa;
- potencial de símbolo/favicon;
- compatibilidad con modo cocina;
- compatibilidad con SEO/editorial;
- capacidad de crecer hacia guías y colecciones.

**La matriz sirve para estructurar la discusión, no para convertir la marca en una competición matemática.**

# 8. HIPÓTESIS DE COMBINACIÓN

Después de esta investigación, existe una hipótesis especialmente interesante:

## BASE B

Tomar de “Manual contemporáneo”:

- estructura;
- numeración;
- sistema;
- precisión;
- símbolo;
- lenguaje de interfaz.

## REFINAMIENTO A

Tomar de “Editorial culinaria”:

- jerarquía;
- tipografía;
- fotografía;
- espacios;
- sensación de autoridad.

## CALIDEZ C

Tomar de “Cocina viva”:

- temperatura de color;
- tratamiento fotográfico;
- pequeños gestos humanos.

Resultado conceptual:

> **Una herramienta culinaria con alma editorial y lenguaje de manual.**

Esta es una **hipótesis de diseño**, no una decisión aprobada.

---

# 9. PRINCIPIO FOTOGRÁFICO

Independientemente de la dirección que se elija:

**la interfaz no debe competir con la comida.**

Por ello:

- fondos predominantemente neutros;
- color de marca controlado;
- tipografía legible;
- imágenes con suficiente espacio;
- cards sin exceso de decoración.

Esto coincide con sistemas de recetas actuales que explícitamente utilizan una base limpia para dejar que la fotografía sea la principal fuente de color y emoción. citeturn0search8

---

# 10. PRINCIPIO DE PRODUCTO

La marca debe seguir siendo reconocible cuando:

- no haya una fotografía;
- haya una fotografía mediocre;
- la pantalla sea pequeña;
- el usuario esté cocinando;
- solo aparezca un botón;
- se muestre un resultado de búsqueda;
- se vea un favicon.

Si la identidad solo funciona en un hero bonito, **no es un sistema de marca suficiente**.
